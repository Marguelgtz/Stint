# Stint GPUI dashboard

An experimental GPUI dashboard with two views. **Deep Work** shows the latest
mission, phase, task statuses, and selected task details. **Interactive** reads
Stint's machine-readable session status and provides guarded start, resume,
deadline, and teardown controls through the existing Go CLI lifecycle paths.

## Run

```sh
cargo run --release
```

This crate was built against `gpui-kit 0.7.3`; `Cargo.lock` pins the GPUI
snapshot that release uses. Linux builds need the native packages listed in
[Zed's Linux development guide](https://github.com/zed-industries/zed/blob/main/docs/src/development/linux.md).

The Interactive view uses the repository-root `stint` binary when present, then
falls back to `stint` from `PATH`. Set `STINT_BIN` to choose a specific
executable. Closing the GPUI window does not stop a running session.

## State source

The dashboard reads the latest session ID from
`${XDG_STATE_HOME:-$HOME/.local/state}/stint/deep/latest`, then loads
`stint/deep/<session-id>/deep.json`. It follows the same latest-session pointer
and JSON field names as Stint's Go coordinator.

The Interactive view runs `stint status --json` every three seconds and adds
passive telemetry about every twelve seconds. It never sends inference traffic
automatically. Start and deadline previews are generated by the Go CLI; the UI
requires confirmation and passes expected offer/session values back so Stint
can reject a stale review before making a change.
